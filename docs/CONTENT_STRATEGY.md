# ESCIM 内容策略 V1（第一阶段）

2026-11-09（Asia/Shanghai）。范围：分类定义、来源审计与契约；不改变现有 UI、数据库、采集、风险引擎或日报。第二阶段才接入生产管线。

| 领域 | 建设优先级 | 收录范围 | 主要排除/约束 |
|---|---|---|---|
| A 物流运营与港口 | P0 | 港口中断/罢工、真实拥堵观测、跳港/停航、船期与危险品运输限制 | 航空泛新闻；公告不等于当前中断；无时间序列不推断拥堵 |
| B 政策贸易合规 | P0 | 欧盟电池法、护照、碳足迹、ADR/IMDG、关税/海关/原产地/制裁 | 不相关中国内销关税；电池义务不得直接套到电解液 |
| C 电池电解液产能 | P1 | 建设、扩产、投产、延迟、停产，电池/OEM/材料企业 | 通用“能力提升”不是制造产能；区分计划和实际投产 |
| D 成本价格 | P1 | 燃油、海运指数、附加费、报价有效期 | EIA柴油/欧盟零售油价只是代理指标，不是船燃或运价 |
| E 地缘环境 | P1 | 明确影响港口、航路、能源或运输的事件 | 普通灾害/安全新闻无明确供应链关联不进入业务流 |
| F 业务影响行动 | P2 | 基于证据的条件性影响、核实任务与行动 | 不假设公司资产、客户、库存、柜号或确定损失 |

机器目录：`config/content_taxonomy.v1.json`；精确事件枚举：`scm.content.contracts.EVENT_KINDS`。一个主领域，多辅助标签；无法分类保留 unknown，不强填。P0/P1/P2 是实施顺序，绝非 high/medium/low 严重度。

## 第二阶段筛选约定（尚未实现）

第一层宽收合规元数据并去重保留来源；第二层按欧洲/国际海运、电池/电解液、政策管辖及明确业务关联决定业务流。excluded 保留理由和审计，不物理删除；不确定为 possibly_relevant，等待核实。相关性、严重度、当前运营状态、证据置信度分别建模。

合成边界用例 `fixtures/content_cases.v1.json` 仅验证分类规范，不是实际新闻或自动分类准确率：欧洲电池工厂投产、欧线跳港、ADR修订和欧盟海关为正例；普通航空新闻、不相关安全新闻、无关联中国关税为负例；已结束罢工只能历史保留，旧发布日期不自动代表当前风险。无明确线路影响的飓风不得直接进入高风险港口流。

## 证据与时效

保留原文引用、定位、来源及版本；摘要事实必须指向证据。潜在影响和建议独立保存，使用条件语气。公布/发生/生效/失效/废止时间分开；未知为 null，日期精度单列，不用抓取时间替代公布时间。政策状态与适用范围须原文依据，不靠日期自动晋级。公告、历史/已解决事件均不能仅凭标题成为“当前已确认中断”。

## 来源覆盖与接入顺序

先 EU MOVE/TRADE/GROW 基线与 UNECE/IMO 规则，再港口/船司运营公告，后补企业产能和成本。各欧委会总司是同一机构，不算多个独立组织。来源矩阵仅候选审计，不自动启用连接器；robots允许不等于正文许可。禁止来源保持 link_only。所有正文许可、日期解析、七日新鲜度和故障隔离需第二阶段实测后才能接受 Live 业务流/日报。

## 读者与输出约定

管理层看已核实变化、潜在规划影响、置信度与下一步；供应链规划团队看国家/港口/线路、日期来源、适用产品、证据及核实问题。未来中文情报卡须含标题、事实、类型、地理、公布/生效时间、条件性影响、跟踪指标、行动、规则风险理由与证据。日报 3–8 条仅在覆盖与证据足够时输出；不足明确说明，不用旧闻凑数。本阶段仅定义输出规范，没有新增摘要/日报逻辑。
